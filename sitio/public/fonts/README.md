TWK Lausanne es de pago (TWKType, twktype.com) — no se puede descargar gratis.

Para activarla:
1. Comprar la licencia webfont en https://twktype.com/collection/twk-lausanne
2. Poner los `.woff2` aquí (ej. `TWKLausanne-400.woff2`, `TWKLausanne-600.woff2`)
3. En `app/globals.css`, agregar el bloque `@font-face` comentado junto a `--font-sans` y apuntar `--font-display` a `"TWK Lausanne"`

Mientras tanto el sitio usa Inter (next/font/google) como base — ponytail: reemplazo temporal, actualizar cuando haya licencia.
