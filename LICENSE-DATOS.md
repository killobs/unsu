# Licencia de los datos / Data license

*English below.*

## Español

Todo el contenido de `datos/` (fichas de sistemas y entidades, líneas base, datos crudos) se publica bajo
**Creative Commons Atribución-CompartirIgual 4.0 Internacional (CC BY-SA 4.0)**.

Texto completo: <https://creativecommons.org/licenses/by-sa/4.0/deed.es>

En resumen, sos libre de copiar, redistribuir, adaptar y usar estos datos, incluso con fines comerciales, siempre que:

1. **Des crédito** — indiques la fuente (`github.com/killobs/unsu`) y si hiciste cambios.
2. **Compartas igual** — si publicás un trabajo derivado de este conjunto de datos, tiene que quedar bajo la misma
   licencia CC BY-SA 4.0 (o una compatible). No podés tomar estos datos, agregarles una capa y cerrarlos.

Esta licencia no es un muro — cualquiera puede volver a extraer los mismos datos de las fuentes oficiales
originales sin depender de este repositorio. Lo que fija es una norma: quien construya sobre el trabajo ya hecho
acá queda obligado a devolver esa misma apertura, no a quedarse con la ventaja de no tener que empezar de cero.

**Atribución adicional obligatoria:** cualquier uso de los registros que provienen de la línea base de Interfases
(`datos/linea-base-interfases.csv` y las fichas de `datos/sistemas/` que la citan como fuente) debe atribuir
además a: Huancapaza Hilasaca, J. E. (2025). *Implementación de inteligencia artificial en el Estado peruano:
catálogo analítico de aplicaciones*. Interfases, (22), 143-158. <https://doi.org/10.26439/interfases2025.n022.8263>

El código fuente (`extractores/`, `sitio/`, `historial/`) tiene una licencia distinta, más permisiva — ver
[LICENSE](LICENSE).

## English

All content under `datos/` (system and entity records, baselines, raw data) is published under
**Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**.

Full text: <https://creativecommons.org/licenses/by-sa/4.0/>

In short, you're free to copy, redistribute, adapt, and use this data, even commercially, as long as you:

1. **Give credit** — cite the source (`github.com/killobs/unsu`) and note any changes made.
2. **Share alike** — if you publish a derivative work built on this dataset, it must carry the same CC BY-SA 4.0
   license (or a compatible one). You cannot take this data, add a layer on top, and close it off.

This license isn't a wall — anyone can re-scrape the same data from the original official sources without
depending on this repository. What it sets is a norm: whoever builds on the work already done here is obligated
to return that same openness, not to keep the advantage of not having to start from scratch.

**Additional mandatory attribution:** any use of records originating from the Interfases baseline
(`datos/linea-base-interfases.csv` and the `datos/sistemas/` entries that cite it as a source) must also credit:
Huancapaza Hilasaca, J. E. (2025). *Implementación de inteligencia artificial en el Estado peruano: catálogo
analítico de aplicaciones*. Interfases, (22), 143-158. <https://doi.org/10.26439/interfases2025.n022.8263>

The source code (`extractores/`, `sitio/`, `historial/`) is under a separate, more permissive license — see
[LICENSE](LICENSE).
